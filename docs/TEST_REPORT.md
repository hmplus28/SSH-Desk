## محیط واقعی تست

- **sshd واقعی** (OpenSSH 9.2p1) روی `127.0.0.1:2222` — احراز کلید، exec، PTY، SFTP، تونل
- **GNOME Keyring واقعی** (48.0) روی D-Bus خصوصی — خط لوله کامل Keyring→AskPass→OpenSSH
- **کلاینت OpenSSH محصول** (10.0p2) برای همه اتصال‌ها
- سرور آزمایشی paramiko فقط برای پذیرش رمز عبور (پورت 2223)

## پوشش E2E (۳۲ سناریو)

- **احراز هویت**: کلید Ed25519، خط لوله رمز عبور، رمز غلط، رمز غایب، override `--user` بدون تغییر DB
- **مسی‌ها**: نام ذخیره‌شده، فاصله/یونیکد، مسیر مطلق، نام نامعتبر با راهنما، مسیر پیش‌فرض
- **امنیت**: پذیرش/ذخیره Host Key با fingerprint، **تغییر کلید میزبان → بلاک کامل (MITM)**، عدم نشت رمز در export، پاک‌سازی Keyring پس از حذف سرور
- **ترمینال/SFTP/تونل**: پوسته PTY تعاملی واقعی، انتقال 20MB با تطابق SHA256، تونل Local و SOCKS5 با قطع واقعی
- **فشار**: ۱۵ سرور موازی (۸ رشته)، ۵ SFTP همزمان، ۵۰ رکورد تاریخچه، سیکل اتصال بدون نشت پروسه ssh
- **CLI**: تغییر نام `sss→cnc` در سطح سیستم‌عامل، تاریخچه، رد نام‌های رزرو/نامعتبر

## اجرا

```bash
SSH_DESK_E2E=1 pytest -m e2e -v      # تست‌های سنگین (نیازمند sshd محلی و keyring)
pytest                                # دور عادی (E2E خودکار skip می‌شود)
ruff check . && mypy src/             # دروازه‌های ایستا
```
